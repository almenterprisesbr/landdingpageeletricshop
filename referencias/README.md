# Referências visuais — ElectricShop

Esta pasta reúne todo o material visual de apoio para o design do site: fotos das lojas, produtos, moodboards e sites concorrentes usados como inspiração.

## Subpastas

- [`fotos-loja/`](fotos-loja/) — Fotos reais das lojas, oficina e ambientes (lifestyle, fachada, showroom).
- [`fotos-produtos/`](fotos-produtos/) — Fotos de produto em estúdio (fundo branco), estilo catálogo.
- [`videos/`](videos/) — Vídeos originais enviados pelo cliente.

## Como adicionar novas fotos ou referências

Pode enviar os arquivos originais (jpg/png/webp/pdf) de uma das formas abaixo:

1. Anexando o arquivo na conversa (se a interface permitir upload/anexo de arquivo, e não apenas colar a imagem inline);
2. Subindo direto pelo GitHub, arrastando os arquivos para dentro da pasta correspondente;
3. Enviando um link de download (Google Drive, WeTransfer etc.).

Sempre que possível, use nomes de arquivo descritivos — por exemplo: `fachada-loja-santos-noite.jpg`, `scooter-cinza-estudio.jpg`.
