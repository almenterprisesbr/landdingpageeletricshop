## ⭐ `video-principal-abertura-site.mp4` — vídeo escolhido para o início do site
**Definido pelo cliente como o vídeo principal de abertura (hero) do site.** (~25,5 MB) Deve ser o primeiro elemento visual que o visitante vê ao entrar no site — candidato natural a vídeo de fundo em tela cheia na seção hero da home, com o logo/CTA sobrepostos.

> Pendente para quando formos implementar: confirmar duração e se precisa ser cortado/comprimido para web (vídeos de hero geralmente ficam entre 10-20s, em loop, sem áudio, e comprimidos para poucos MB — vamos tratar isso na fase de construção do site).
